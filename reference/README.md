# Reference editions

These are reference witnesses and access points. They are not alternative source
passages silently substituted into the selected 易學網 transcription.

## 易學網's linked facsimile

Each imported page's `scan_urls` in [the manifest](../provenance/manifest.json) links to
its associated facsimile leaves. The [juan 20 opening](https://www.eee-learning.com/eeebook/middleyi/1998.png)
was inspected to verify the 易學啓蒙 volume boundary; it identifies the facsimile as
欽定四庫全書薈要. The complete scan set has not been manually collated.

## Collation practice

Check a questionable character or missing-looking passage against an image witness
before changing the reading text. Record the witness, juan, and leaf or image URL in
an explicit note. Keep additions and emendations separate from the untouched capture.
A preface date should not by itself be treated as a particular copy's printing date.
